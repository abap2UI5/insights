# Inter

`inter-roman-latin.woff2` is the Latin subset of **Inter**, by Rasmus
Andersson, variable weight 100–900, licensed under the **SIL Open Font
License, Version 1.1** (<https://github.com/rsms/inter>).

It is committed rather than fetched from a font CDN: the page loads nothing
from anywhere else (its Content-Security-Policy says so), and every reader gets
the same face, so a line that fits for the author fits for the reader.
